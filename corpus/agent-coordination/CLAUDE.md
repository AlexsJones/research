# Agent Coordination Research Project

## Context

This project researches **Agent-to-Agent Operational Coordination** — the missing coordination layer between AI agents. It builds on the "Synthetic Membrane" position paper which argues that multi-agent systems lack a shared, permeable boundary for coordination.

## Directory Structure

- `corpus/` — structured research entries (one per topic)
- `analysis/` — evolving synthesis and thesis
- `references/` — raw reference materials
- `output/` — article drafts and paper drafts

## Core Theory

There is a missing **coordination layer** that doesn't exist in current agent frameworks. Current approaches (LangGraph, CrewAI, AutoGen, A2A, MCP) rely on message passing or orchestration. None provides ambient, persistent, structured coordination.

## Focus Area

**Operational Coordination**: How agents can be used in incident management to follow hypotheses and work together. Key questions:
- What do incident management frameworks (ICS, NIMS) teach us about coordination?
- How do agents coordinate hypotheses in security incident response?
- What primitives are needed for operational coordination?

## Research Methodology

1. Survey current agent frameworks and their coordination capabilities
2. Identify specific gaps and flaws
3. Cross-domain analysis (ICS, swarm intelligence, distributed systems, biology)
4. Case studies from incident management
5. Academic literature review

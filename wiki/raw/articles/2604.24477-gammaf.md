# GAMMAF: Graph-Based Anomaly Monitoring Benchmarking in LLM Multi-Agent Systems

## Summary
- Open-source benchmarking platform for graph-based anomaly detection in LLM MAS
- Defense systems that detect and isolate adversarial nodes recover system integrity
- Attack remediation substantially reduces overall operational costs

## Relevance to Membrane
Directly relevant to the Immune Layer. Provides a benchmarking framework for detecting adversarial agents in multi-agent systems. Shows that equipping MAS with attack remediation reduces operational costs by cutting off token generation from adversarial agents.

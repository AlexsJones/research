# How Memory Can Affect Collective and Cooperative Behaviors in LLM-Based Social Particle Swarm

## Summary
- Memory length is a critical parameter: minimal memory suppresses cooperation
- Longer memory transitions from cooperative clusters to scattered defection
- Model alignment plays fundamental role in emergent social behavior
- Gemini vs Gemma show opposite trends based on how they interpret memory

## Relevance to Membrane
Critical for Layer 3 (Coordination) and Layer 1 (Trust). Shows memory length critically governs collective behavior. Supports our argument that structure between agents, not just memory, produces cooperation.

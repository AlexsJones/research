# Spore: Efficient and Training-Free Privacy Extraction Attack on LLM Agent Memory

## Summary
- Single-query privacy extraction attack on LLM agent memory
- Compatible with black-box and gray-box settings
- Consistently bypasses detection and safety alignment

## Relevance to Membrane
Relevant to Immune Layer and Layer 1 security. Demonstrates that agent memory systems are vulnerable to privacy extraction attacks. Supports the argument that default-deny permeability is essential.
